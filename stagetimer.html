Stage Timer

v0.9.2 · Windows 10/11

A timer, countdown and clock for speakers, presentations and live shows. Drive it from the control window, a browser or Bitfocus Companion, and send the output to a monitor, as NDI or as a web page.

Overview
How it works
Three timer modes
Countdown, count up, or count to a time of day. Play, pause and reset, and add or remove time while it runs — from a quick +1m to any amount.
Colours and thresholds
A base colour plus two thresholds, each with optional flashing, and a dedicated end / overtime style. At zero the timer can stop or keep counting into overtime.
Flexible output
Timer, clock, blackout or test patterns. Free layout with snap, solid or transparent background, windowed or fullscreen on the monitor you choose, plus free-text messages.
NDI and web output
The same picture as an NDI source (with optional alpha) and as a web page, ready to use as a browser source. NDI needs the free NDI Tools on the PC.
Presets and rundown
Twelve preset buttons, a rundown with planned start times and cumulative delay, and showfile export / import for a complete backup of the show.
Remote control and Companion
Full web control page, HTTP / WebSocket API and a dedicated Bitfocus Companion module with actions, feedbacks, variables and ready-made buttons.
Built for the show
Time is computed from the system's monotonic clock. Web server, NDI and output are isolated from the timer: a failure in one of them never stops the count.
