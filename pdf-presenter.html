PDF Presenter

v2.3.2 · Windows 10/11

A Windows application for PDF presentations at live events. One control window drives a Presentation output for the audience and a Speaker output for the presenter, with remote control from any device and from Bitfocus Companion — fully offline.

Overview
How it works
Presentation and Speaker outputs
Two independent outputs, each on the display you choose, fullscreen or windowed. The Speaker view shows current and next slide, notes, elapsed time, a clock and messages from the control room.
PDF library
Open a whole event folder, subfolders included, and pick the file to show. The list updates by itself when files are added or removed.
Black and Freeze
Black out the audience output, or freeze it on the current picture while you change slide or open the next speaker's PDF — the audience sees nothing change.
Fade between slides
Optional crossfade on the Presentation output with an adjustable duration, plus an all-slides grid and PowerPoint-style jump by typing a slide number.
Per-slide notes
Editable notes for every slide, saved automatically next to the PDF and shown on the Speaker output.
Remote control
A speaker web page with previous / next, a full operator web page and an HTTP API for Bitfocus Companion and other control software.
Safe on show day
Detects a PDF replaced or modified while the show is running and offers a reload. Everything, PDF engine included, runs offline.
